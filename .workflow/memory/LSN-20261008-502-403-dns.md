三类现象各自的实测判据：
1. 502 {"message":"upstream request failed: fetch failed"} 且 cause 是 ERR_TLS_CERT_ALTNAME_INVALID -> 本地 DNS 把 opencode.ai 污染成 182.16.62.234（该 IP 证书 SAN 只有 IP）；真实是 Cloudflare 172.65.90.20~23（8.8.8.8/9.9.9.9 可查）。让插件走本机代理即绕过（代理解析域名，本地 DNS 不再参与）。
2. 403 {"type":"RegionError","message":"This model is not available in your country."} -> 出口地区问题，不是请求体问题。判据：同一台机器走代理 POST /zen/v1/responses 得 200，而 proxyUrl=off 强制直连时 responses 403、chat 仍 200。
3. 403 FreeTierError -> 免费通道门禁未过：请求体必须流式、tools 必须含名为 bash 与 read 的函数工具；responses 通道还要用扁平工具形状且**不写 tool_choice**（写 none 会被 400 `only "auto" is supported for tool_choice` 拒）。

环境事实（非代码 bug）：本机代理节点爱抖动——curl 实测 5 次里 2 次 TLS 握手失败，成功的要 10s 级。代码侧的正确反应是等待重拨（见路由铁律），不是改走直连。

另一处已修的细节：代理「干净关闭」（FIN 而不回 CONNECT 响应）必须立刻判该次拨号失败——lib/proxy.js 的 httpConnectTunnel 里加了 onClose 拒绝路径，否则会空等 12s 隧道超时。
